    client-side via asyncio.wait_for — prevents /health hanging forever when no
    worker is polling), CATALOG_CACHE_TTL (30s).
  - orchestrator/catalog_workflow.py (new module):
      set_catalog(catalog) / _CATALOG module registry (mirrors
      think_activity.set_model_factories's pattern — worker-process state, never
      a workflow payload).
      @activity.defn(name="model_catalog") async def model_catalog() -> list[RegisteredModel]
      @workflow.defn class ModelCatalogWorkflow with .run() executing exactly the
      one activity with CATALOG_ACTIVITY_TIMEOUT as start_to_close_timeout.
  - run_worker.py: imports ModelCatalogWorkflow/model_catalog/set_catalog; calls
    set_catalog(catalog) right after assemble_model_factories(); registers
    ModelCatalogWorkflow in workflows=[...] and model_catalog in activities=[...].
  - server.py:
      _catalog_cache = {"models": None, "fetched_at": 0.0}
      _execute_catalog_workflow(): client.execute_workflow(ModelCatalogWorkflow.run,
        id=f"model-catalog-{uuid4()}", task_queue=TASK_QUEUE,
        execution_timeout=CATALOG_WORKFLOW_TIMEOUT) wrapped in
        asyncio.wait_for(..., timeout=CATALOG_WORKFLOW_TIMEOUT); any exception ->
        [] (fail closed).
      model_catalog(refresh=False): TTL-cached; empty results are never cached
        (so a worker coming up is picked up immediately, not after a stale TTL).
      validated_model(model_id): 503 when catalog is empty, one forced refresh on
        a plain cache miss (not on an already-empty catalog, to avoid doubling the
        wait before a 503), 400 with a preview of available ids otherwise.
      GET /health: liveness == task_queue_has_pollers() only (unchanged
        DescribeTaskQueue helper at server.py ~:112-145). Payload keys are exactly
        {status, temporal, worker, pollers, models, providers, default_model} —
        "worker" is now pollers_ok itself (a worker IS its pollers); "models" is
        the full list of {id, provider, label} objects (no model_ids, no count).
        "providers" = config.PROVIDER_DISPLAY_NAMES. default_model = DEFAULT_MODEL_ID
        if present in the catalog else the first catalog entry, else None.
      POST /sessions and POST /sessions/{id}/turns/stream: model_id validated via
        validated_model() against the cached (refresh-on-miss) catalog.
      POST /compare/stream: model_ids validated against the same cached catalog,
        with one refresh before rejecting on any miss.
