Task 6 — framework-adherence-reset: shrink orchestrator/gemini_model.py stream() to thin super().stream() wrapper
Date: 2026-09-08

## Change summary
- Deleted the full copied parent stream loop (~92 lines, former :252-343).
- stream() now: sets self._reasoning_effort from invocation_state; resets self._grounding = {};
  `async for chunk in super().stream(...)`: yield chunk; then appends trailing
  {"gemini": search} / {"gemini": maps} frames from the grounding sink; clears effort in finally.
- reasoning_effort merged in an override of _format_request_config (parent strands/models/gemini.py:291),
  which receives the params dict — {"thinking_config": {**existing, "thinking_level": effort}}.
  self.config["params"] is never mutated (params dict is rebuilt, not written through).
- Grounding captured via _get_client() override returning _GroundingTapClient(super()._get_client(), sink):
  proxy whose .aio.models.generate_content_stream(**kw) awaits the real call and wraps the async
  iterator, calling existing maps_from_grounding/search_from_grounding on each raw event, storing the
  latest non-None result on the sink, yielding every event unchanged.
- Error handling (ClientError -> ModelThrottledException / ContextWindowOverflowException) now comes
  entirely from the parent; local match block deleted. Unused `copy` import and exception imports removed.
- KEPT unchanged: _format_request_content, _computer_use_function_response,
  _format_request_content_part (video + computer-use), _format_request_tools.
